   # Sales Data Analysis
   
   Analyzed a superstore sales dataset (~9,800 records) using Excel PivotTables to identify top and bottom performing regions and product categories.
   
   ## Key Findings
   - West region had the highest total sales; South had the lowest
   - Technology was the top-selling category across all regions
   
   ## Tools Used
   Excel (PivotTables), data cleaning, aggregation
